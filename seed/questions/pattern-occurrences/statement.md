Given a text `T` and a pattern `P`, both made of lowercase English letters, count the positions where `P` occurs in `T`. Occurrences may overlap.

## Input

The first line contains the text `T`.

The second line contains the pattern `P`.

## Output

Print the number of occurrences of `P` in `T`.

## Constraints

- `1 ≤ |T| ≤ 900000`
- `1 ≤ |P| ≤ 100000`
- Both strings contain only the letters `a` to `z`.

## Examples

### Example 1

**Input**

```text
abababa
aba
```

**Output**

```text
3
```

### Example 2

**Input**

```text
codeclash
zz
```

**Output**

```text
0
```
