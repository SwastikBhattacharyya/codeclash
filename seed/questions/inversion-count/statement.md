An inversion in a sequence `a1 a2 … an` is a pair of positions `i < j` with `a_i > a_j`. Count the inversions.

## Input

The first line contains an integer `n`.

The second line contains `n` integers `a1 a2 … an`.

## Output

Print the number of inversions.

## Constraints

- `1 ≤ n ≤ 150000`
- `1 ≤ a_i ≤ 100000`

## Examples

### Example 1

**Input**

```text
5
3 1 4 1 2
```

**Output**

```text
5
```

### Example 2

**Input**

```text
3
1 2 3
```

**Output**

```text
0
```
