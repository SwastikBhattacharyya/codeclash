You are given a sequence of `n` integers. A subsequence keeps some of the elements in their original order, not necessarily adjacent.

Find the length of the longest subsequence whose elements are **strictly increasing**.

## Input

The first line contains an integer `n`.

The second line contains `n` integers `a1 a2 … an`.

## Output

Print the length of the longest strictly increasing subsequence.

## Constraints

- `1 ≤ n ≤ 150000`
- `1 ≤ a_i ≤ 100000`

## Examples

### Example 1

**Input**

```text
8
4 1 5 2 6 3 7 2
```

**Output**

```text
4
```

### Example 2

**Input**

```text
4
3 3 3 3
```

**Output**

```text
1
```
